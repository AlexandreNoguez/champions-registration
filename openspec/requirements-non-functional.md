# Requisitos não funcionais

## Usabilidade
- A interface deve ser intuitiva e responsiva para dispositivos móveis e desktops.
- A experiência visual deve ser moderna, com Material UI.

## Segurança
- Os dados sensíveis devem ser tratados com cuidado.
- O sistema deve validar e sanitizar entradas do usuário.

## Desempenho
- O formulário deve responder rapidamente durante o cadastro.
- A API deve processar inscrições sem atrasos perceptíveis.

## Confiabilidade
- O sistema deve lidar bem com falhas simples de conexão com o banco.
- O processo de inscrição deve ser consistente e previsível.

## Manutenibilidade
- O código deve seguir uma estrutura organizada em Next.js.
- A lógica de validação e persistência deve ser separada para facilitar evolução.

## Custos
- O projeto deve permanecer 100% gratuito no deploy e no banco em fase inicial.
- O uso do MongoDB Atlas gratuito e da Vercel deve ser suficiente para a versão inicial.
